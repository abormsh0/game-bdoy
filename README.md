# بدوي — بداية جديدة

نسخة جديدة قابلة للعب من لعبة بدوي، بمنظور شخص أول في صحراء سعودية مبسطة. يبدأ اللاعب بعشر نياق وجمل، ويتحرك بينها بالعصا أو لوحة المفاتيح.

## الموجود في النسخة

- عالم ثلاثي الأبعاد فعلي بمخيم وماء ومرعى وسوق.
- حركة مستقلة لكل ناقة، ونداء يجعل القطيع يتبع اللاعب.
- سقي وإطعام ولمس وحلب، مع مخزون ومؤشرات غذاء وماء وصحة.
- مهمة يومية: سقي ثلاث نياق مختلفة وإطعام ثلاث نياق، ثم العودة للمخيم للحصول على 250 ريال.
- حلب لترين من الناقة المروية والشبعانة مرة في اليوم، وبيع الحليب في السوق.
- يوم افتراضي مدته 600 ثانية؛ تمر الفصول الأربعة خلاله، ويظهر تعاقب الليل والنهار.
- قوائم وأيقونات صغيرة، وخريطة وعلامات اتجاه، وتحكم باللمس.
- حفظ تلقائي كل 15 ثانية وبعد التفاعلات، على الجهاز والمتصفح الحالي.

## التشغيل

المتطلبات: Node.js 22 أو أحدث وnpm. مكتبة Three.js مثبتة على الإصدار 0.180.0. كل ملفات التشغيل تُخدم من المشروع، ولا تستخدم مكتبة الرسوم رابط CDN أثناء اللعب.

~~~bash
npm install
npm run build
npm run check
npm test
npm start
~~~

افتح http://localhost:3000. للمشاركة على الشبكة المحلية استخدم عنوان الجهاز المضيف مع المنفذ نفسه. لفتح اللعبة على الهاتف خارج الشبكة، ارفع مجلد dist إلى استضافة HTTPS.

## التحقق والحدود

اجتازت النسخة 22 اختبارًا آليًا، وفحص صياغة JavaScript ووجود الملفات المحلية. اختبارات المشهد تتحقق من المجسمات والبيانات؛ لا تشغل WebGL داخل متصفح. لم يُجرَ اختبار بصري في Safari أو اختبار لمس على آيفون فعلي، ولم يُنفذ سير GitHub Actions بعد رفعه.

هذه رسوم هندسية مبسطة لإثبات اللعب، وليست الرسوم الواقعية في الصور المرجعية. الصور لم تدخل اللعبة كخلفية ثابتة. مؤثرات الصوت إشارات قصيرة فقط. لا تتضمن النسخة تكاثر الإبل أو مراحل عمرها أو شراء الإبل أو لعبًا جماعيًا. لا يوجد تثبيت متجر أو ضمان عمل دون اتصال.

يمكن إضافة رابط HTTPS إلى الشاشة الرئيسية من قائمة المشاركة في Safari. هذا اختصار للنسخة المتصفحية، وليس إصدار App Store.
