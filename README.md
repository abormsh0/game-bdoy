# game-bdoy 🎮

مستودع تطوير اللعبة.

## الهدف

بناء **MVP صغير وقابل للعب** أولًا، ثم التوسع تدريجيًا بعد اختبار أسلوب اللعب الأساسي.

## استراتيجية التطوير

- `main`: النسخة المستقرة فقط.
- `develop`: فرع التطوير اليومي ودمج الميزات.
- `feature/<name>`: فرع مستقل لكل ميزة جديدة.

## مراحل البداية

1. تحديد نوع اللعبة والمنصة المستهدفة.
2. اختيار محرك اللعبة والتقنيات المناسبة.
3. تعريف حلقة اللعب الأساسية Core Gameplay Loop.
4. بناء Prototype قابل للعب.
5. اختبار التجربة وتثبيت نطاق الـMVP.
6. إضافة المحتوى والواجهة والحفظ والصوت تدريجيًا.

## هيكل المستودع

- `docs/`: تصميم اللعبة وخطط التطوير.
- ملفات المحرك والكود ستضاف بعد اختيار التقنية المناسبة.

## قاعدة المشروع

> لا نبني أنظمة كبيرة قبل إثبات أن أسلوب اللعب الأساسي يعمل وممتع.

## أول وثيقة

راجع `docs/MVP.md` لتحديد نطاق النسخة الأولى قبل بدء البرمجة.
