# بدوي: نطاق النسخة الأولى الجديدة

## الهدف

يمشي اللاعب بين قطيعه، يرعى ثلاث نياق بالماء والعلف، ويعود إلى المخيم لاستلام مكافأة. يبيع الحليب ويشتري المؤن ليتابع الأيام.

## المنصة والتقنية

متصفح حديث على الهاتف والكمبيوتر يدعم WebGL 2. تبدأ النسخة كتطبيق ويب عربي، باستخدام JavaScript وThree.js 0.180.0. اختيرت نسخة ويب لتقديم تجربة واحدة عبر رابط على الجوال والكمبيوتر. الرسوم مبسطة؛ الانتقال إلى إنتاج بصري واقعي واسع سيحتاج إعادة تقييم المحرك وأصول الرسوم.

## معايير النسخة الحالية

| المعيار | التنفيذ |
| --- | --- |
| بداية مفهومة | شاشة بداية وتعليمات قصيرة |
| منظور شخص أول | كاميرا تتحرك وتلتفت، مع يد مبسطة |
| قطيع البداية | 10 نياق وجمل، لكل منها حركة وحالة |
| حلقة لعب كاملة | رعاية ← رجوع للمخيم ← مكافأة ← حلب وبيع ← مؤن |
| هدف الجولة | ماء لثلاث نياق وعلف لثلاث نياق مختلفة |
| نتيجة واضحة | مكافأة 250 ريال وإعلان إتمام المهمة |
| إعادة البداية | إعدادات ← بدء عالم جديد ← تأكيد |
| استمرار اللعب | حفظ محلي ومهمة تتجدد كل يوم |
| مدة اليوم | 10 دقائق من الوقت الذي تكون اللعبة فيه نشطة |
| الفصول | فصل كل دقيقتين ونصف؛ أربع فصول خلال اليوم، وفق فكرة المستخدم |

القوائم وإخفاء الصفحة يوقفان المحاكاة. النوق تتحرك بنفسها، وتشرب وترعى قرب المحطات إذا احتاجت. النداء يغيّر سلوكها إلى متابعة اللاعب.

## نطاق الحفظ

يحفظ الوقت والرصيد والمخزون والحليب وموضع اللاعب وحالات القطيع وإنجاز المهمة والإعدادات. البيانات محلية لكل متصفح؛ تغيير الجهاز أو مسح بيانات الموقع يفقد هذا الحفظ. لا توجد محاكاة أثناء إغلاق اللعبة.

## الفحص الآلي

22 اختبارًا تغطي الحركة والاصطدام والنداء وتوجيه الهدف وشروط الرعاية والحلب والشراء والبيع ومنع تكرار المكافأة والحفظ التالف وانقطاع اللمس ووجود مجسمات القطيع. فحص مستقل يراجع صياغة JavaScript والملفات المرتبطة.

لم يُختبر العرض داخل متصفح فعلي في بيئة التنفيذ الحالية. يلزم تشغيل الجولة على آيفون قبل اعتماد راحة التحكم ومعدل الإطارات.

## التجربة الأولى

1. افتح اللعبة واضغط ابدأ رحلتك.
2. اقترب من وضحا، واختر الماء واضغط اسقِ، ثم العلف واضغط أطعم.
3. كرر الرعاية مع ناقتين مختلفتين.
4. افتح الخريطة وحدد المخيم، وارجع لاستلام المكافأة.
5. احلب ناقة مروية وشبعانة، ثم اتبع علامة السوق وبع الحليب.
6. أعد فتح الرابط وتحقق أن التقدم استمر.

## مؤجل إلى ما بعد تجربة التحكم

مجسمات إبل واقعية، أصوات محيطية، تكاثر ومراحل عمر موثقة، شراء الإبل وبيعها، مهام إضافية، وحفظ سحابي. ملف الفكرة الأصلي مرجع تصميم؛ جدول أعمار الإبل فيه لم يُعتمد كبيانات بيولوجية في هذا النموذج.

الخطوة القادمة: تجربة الجولة على الآيفون وتسجيل أي صعوبة في الحركة أو تحديد الناقة.
