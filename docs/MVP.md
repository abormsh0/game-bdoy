# Game MVP

هذه الوثيقة تحدد النسخة الأولى القابلة للعب قبل التوسع.

## 1. فكرة اللعبة
اكتب وصفًا من سطر واحد:
> اللاعب يقوم بـ ______ بهدف ______ بينما يواجه ______.

## 2. المنصة المستهدفة
- [ ] Web
- [ ] Windows
- [ ] Android
- [ ] iOS
- [ ] أخرى

## 3. أسلوب اللعب الأساسي
حدد الحلقة التي سيكررها اللاعب:

1. يبدأ اللاعب.
2. ينفذ الفعل الأساسي.
3. يحصل على نتيجة أو مكافأة.
4. تزداد الصعوبة أو يتغير التحدي.
5. يعيد الحلقة.

## 4. شروط الـ MVP

### يجب أن يحتوي
- شاشة بداية بسيطة.
- جولة لعب واحدة كاملة.
- حركة أو تحكم أساسي.
- هدف واضح للاعب.
- فوز أو خسارة.
- إعادة تشغيل الجولة.

### لا نضيف الآن
- متجر.
- تسجيل دخول.
- تعدد لاعبين.
- نظام اجتماعي.
- تخصيص متقدم.
- عشرات المراحل.
- أنظمة اقتصاد معقدة.

## 5. قرارات نحتاجها قبل البرمجة
- نوع اللعبة.
- منظور اللعبة: 2D أو 3D.
- المنصة الأولى.
- هل تحتاج اتصالًا بالإنترنت؟
- هل اللعب فردي أم جماعي؟
- محرك اللعبة.

## 6. تعريف النجاح
الـMVP ناجح عندما يستطيع لاعب جديد:
1. فتح اللعبة.
2. فهم المطلوب بدون شرح طويل.
3. لعب جولة كاملة.
4. معرفة هل فاز أو خسر.
5. إعادة المحاولة بسهولة.

## 7. أول Milestone
**Playable Prototype**

الهدف: إثبات أن الفكرة الأساسية ممتعة قبل الاستثمار في الرسوم، الحسابات، المتجر أو الأنظمة الكبيرة.
